# 👋 Wire B

> Wire B is a chat app UI built by [cssninjaStudio](https://cssninja.io).

![Screenshot](https://media.cssninja.io/products/wire-b/product.png "Wire-B")

## ✌️ preview

Check out the live demo by clicking [here](https://wire-b.cssninja.io/).
Wire B is built with [Bootstrap](https://getbootstrap.com/) and [Alpine JS](https://github.com/alpinejs/alpine).

## 👍 Features

- Gulp 4 and nodejs 12.20.0 to 16.0.0
- Bootstrap 5x
- ES6 support
- Alpine v3

## 👌 Usage

1. Install Dev Depedencies

```sh
yarn install
```

2. To start development server

```sh
yarn dev
```

3. Build for production

```sh
# build the dist folder
yarn build
```
